# Exporter

EPUB/PDF ska byggas utan innehållsförteckning i början om inget annat anges.

Exporten ska endast innehålla:
- Titelblad
- Romantext från `kapitel/kapitel-XX.md`

Följande filer ska aldrig inkluderas i EPUB/PDF:
- `kapitelnoteringar.md`
- `revisionsonskemal.md`
- `arbetslogg.md`
- `projektstatus.md`
- `project-index.md`
- `roman-bibel.md`
- `synopsis.md`
- `tidslinje.md`
- `kontinuitetsanteckningar.md`
